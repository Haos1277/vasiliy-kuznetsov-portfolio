# Портфолио Василия Кузнецова

Персональный сайт фотографа, видеографа, AI-креатора и музыканта DJ_Schmied.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

## Публикация

Сайт автоматически собирается и публикуется в GitHub Pages после отправки изменений в ветку `main`.
